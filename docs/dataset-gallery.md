## 四、答辩现场怎么讲（4 步）

1. **先报总数**：`fire-smoke-v2-640` 共 **21,527 张**（train 15,500 / val 1,721 / test 4,306），
   标注框 **26,539 个**，负样本 9,838 张。下面 10 张拼图把每一张图都画进去了，不是抽样。
2. **打开 [`train-01.png`](samples/train-01.png)**：64 列 × 35 行、2,215 格，**每一格都是一张真实图片**
   （顶部 30 px 是标题栏）。第 1 页同时有明火 524 格、烟雾 664 格、负样本 1,027 格。
3. **指出边框含义**：红 = 有明火框，橙 = 有烟雾框，灰 = 背景负样本（无标注或空标注）。
   三种颜色在第 1 页都能直接数出来，说明拼图不是只挑了正样本。
4. **说明小目标占比**：**7,827 个框面积 <1% 画面**（训练集 45.1%；三个划分合计 11,838 个、44.6%），
   目标最短边中位数 **43.7 px**、10% 分位 **12 px** —— 所以输入用 640、训练要多尺度，
   单张缩略图里很多火焰只占几个像素，属于正常现象。

## 五、现场重跑

拼图由 `scripts/dataset_sheets.py` 生成，可在答辩现场直接重跑（拼图约 1–2 分钟，含统计复核约 3–6 分钟；
首次读盘冷缓存会慢一些，8 线程、40 px 缩略图）：

```powershell
ai\.venv\Scripts\python.exe scripts\dataset_sheets.py
# 只画 fire-smoke-v2-640 三个划分：
ai\.venv\Scripts\python.exe scripts\dataset_sheets.py --only-catalog
# 只重画训练集 7 页（val/test 页不动）：
ai\.venv\Scripts\python.exe scripts\dataset_sheets.py --splits train
```

脚本会先清理同名旧页再重画，重复运行结果一致；常用参数：

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `--splits train,val,test` | 三个都画 | 选择训练集划分 |
| `--only-catalog` | 关 | 跳过 4 个旁路数据集 |
| `--thumb 40` | 40 | 缩略图边长（px） |
| `--cols 64` | 64 | 每行图片数（64 × 40 = 2560 px 宽） |
| `--order shuffle` | shuffle | 页内顺序：固定种子打乱（`--order list` 用原始列表顺序） |
| `--seed 42` | 42 | 打乱种子，保证每次生成的页面一致 |

## 六、口径说明

- **页内顺序**：默认按固定种子（42）打乱。`train.txt` 按来源成块排列，前 2,215 张里
  2,209 张是雨天远景负样本，整页几乎全灰，现场无法在同一页指出红/橙/灰；打乱只影响页内顺序，
  **覆盖的仍是全部图片，无遗漏、无重复**（每页张数之和 = 该划分图片数）。
  需要原始顺序时加 `--order list`。
- **负样本定义**：没有标注文件，或标注文件为空/没有任何合法行（每行需 5 列），
  都按背景负样本处理（灰框）。
- **缩略图只用于证明覆盖与类别分布**，看不清细节属正常；单张细节看 `docs/dataset-samples.png`
  （64 张抽样样张，旧版）或原始图片。
- 生成清单（机器可读）：`ai/runs/dataset-sheets.json`，每个划分的页数、每页首尾序号、
  失败格数、页面尺寸都在里面；本次生成失败格数为 0。
