## 五、统一写作规范

1. **文档结构**：封面（项目名/文档名/编号/版本/编制人/日期）→ 版本历史 → 目录 → 正文 → 附录；标题层次最多三级。
2. **格式**：A4，页边距上下 2.54cm、左 3.0cm、右 2.6cm；正文宋体五号、1.5 倍行距；一级标题黑体三号，二级黑体四号，三级黑体小四；图表居中并编号（图1、表1），表头深蓝底白字。
3. **命名**：`任务N_文档名_v版本_日期.docx`，例：`任务3_需求规格说明书_v0.1_0912.docx`。
4. **每章标注负责人**：如"（本节负责人：李汶航）"，便于个人工作量认定。
5. **版本流程**：v0.1 起草 → v0.5 组内评审 → v1.0 定稿；保留每次修改记录。
6. **过程材料**：每人材料放 `docs/课程任务/过程记录/<姓名>/`，文件命名带日期。
