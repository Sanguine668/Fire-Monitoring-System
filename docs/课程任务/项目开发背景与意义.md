> 版本 / 日期：v1.0 / 2026-09-14

## 一、项目开发背景

火灾具有突发性强、蔓延速度快、破坏后果严重的特点，能否在起火初期及时发现并处置，直接决定损失规模。传统火灾监测主要依赖烟感探测器与人工巡查：烟感设备受安装位置和覆盖范围限制，在大空间、室外场地、林区等场景中难以有效覆盖；人工巡查存在时间盲区，夜间与无人值守时段尤其容易漏检。随着视频监控在园区、仓库、生产线与林区的大量部署，利用摄像头画面自动识别火焰与烟雾，成为提升早期预警能力的一条可行路径。

与此同时，深度学习目标检测技术已经相对成熟，YOLO 系列模型在精度与推理速度上能够满足视频实时检测的需求；单台带独立显卡的笔记本即可完成模型训练与多路视频推理，安卓手机也可以通过 IP Webcam 等应用把摄像头画面推流到局域网，硬件门槛明显降低。也就是说，制约"视频烟火监测"落地的关键已不再完全是算法与算力，而是数据质量、误报控制与工程实现的完整度。

但从现有公开资源看，问题依然突出：多数开源烟火检测项目停留在实验室近景演示，训练数据以网络采集图片为主，存在重复图片多、分辨率偏低、近景大火样本占比过高、远距离小目标样本稀缺等问题；同时，灯光、夕阳、蒸汽、云雾等干扰容易被误判为烟火，导致告警可信度下降。本项目的现有数据集经过体检也证实了这些情况：2059 张图片中仅标注 fire 一类，存在 57 组精确重复与 149 组近重复，67% 的图片宽度不足 640 像素，小目标占比只有 14.7%。这些问题使得"看得懂、报得准、演示得出来"成为本项目必须同时解决的三件事。

## 二、项目开发意义

从应用价值看，系统面向园区、仓库与林区等场景，能够复用现有摄像头或直接用手机作为移动视频源，实现对火焰与烟雾的实时识别和分级预警；通过"连续帧确认 + 置信度阈值 + 告警冷却"的规则设计减少单帧误报，并通过告警记录、确认处理与统计图表形成完整的处置闭环，帮助值班人员更快发现和核实风险，降低漏检与误报带来的管理成本。

从技术价值看，项目不仅集成检测模型，还建立了"数据获取—质量体检—清洗去重—防泄漏划分—训练评测"的数据治理流程，并将自训练模型与公开模型进行量化对比；在此基础上引入切片推理提升远距离小目标检出，引入智能体复核（时序融合与视觉模型二次判断）降低复杂场景误报，形成一套可对比、可迭代、可在单机上部署的低成本技术方案，对同类视频监测项目的工程实现具有参考意义。

从教学与管理价值看，项目按软件项目管理的完整过程推进：需求获取与分析、系统设计与接口定义、迭代开发与联调、测试与验收、进度规划与风险控制、文档编制与版本管理。小组使用 Git 分支协作与 Microsoft Project 进行任务分解和进度管理，模型指标、测试记录与过程材料均可追溯，既锻炼了团队协作与工程规范意识，也使课堂演示成果具备可验证、可复现的支撑。

## 三、精简版（约 150 字，供章程/软件介绍直接引用）

火灾早期发现直接影响损失规模，而传统烟感与人工巡查在大空间、室外和无人值守场景中覆盖有限；现有开源烟火检测方案又普遍存在数据重复、分辨率低、近景样本偏多与误报率高的问题。本项目利用现有摄像头与手机推流画面，结合自训练 YOLO 模型、分级预警规则、切片远距离检测与智能体复核，构建低成本、可演示、可追溯的视频火情监测预警系统，既提升早期发现与误报控制能力，也完整实践软件项目管理的开发与文档流程。
