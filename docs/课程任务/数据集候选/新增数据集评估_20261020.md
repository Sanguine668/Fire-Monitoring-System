# 组员补充数据集评估（2026-10-20）

## 一、结论

本轮补充材料没有改变训练主线：**训练仍以 D-Fire 为主**，陈泽恩提供的负样本与远景图用于**误报率与远景能力评测**，不混入训练集；欧阳宇康的 SmokeFire 只交付了抽样与统计报告，**原始数据包未随材料提交**，暂不能用于训练。

这样处理的原因有两点：

1. 评测集必须与训练集来源隔离，否则“误报率下降”“远景召回提升”会被数据泄漏污染；
2. 补充包大多没有统一标注（Pyronear 只有正样本图片，负样本包没有逐张标签），直接混入训练会引入噪声标签。
