## 二、导入 Project 的步骤

1. 新建空白项目，设置**项目开始日期**为 2026-09-03（项目 → 项目信息 → 开始日期）；
2. 在"更改工作时间"中把 2026-10-01 ~ 2026-10-07 设为非工作日；
3. 建议保持**自动计划**模式（见第三节说明）；
4. 复制上表（不含表头）粘贴到任务列表，或用"文件 → 打开 → 浏览 → 选择 CSV"导入（配套 `Project任务清单.csv` 含"层级"列：1=摘要任务，2=子任务，导入后按层级缩进）；
5. 摘要任务：选中子任务后点"降级"缩进到对应摘要任务下；摘要任务的开始/结束由子任务自动汇总；
6. 里程碑：把工期改为 0 天，Project 会自动显示为菱形里程碑；
7. 填前置任务与资源名：前置任务列填"行号"（如 12 或 25、26），资源名可直接粘贴分配；
8. 完成录入后切换到"甘特图"视图，检查关键路径（任务格式 → 勾选关键任务），并截图用于任务4说明书。

## 三、手动计划 vs 自动计划（Project 的两种任务模式）

| 对比项 | 自动计划（Auto Scheduled） | 手动计划（Manually Scheduled） |
| --- | --- | --- |
| 日期由谁决定 | Project 根据工期、前置任务、日历和资源自动计算 | 由你手工输入并固定，Project 不自动调整 |
| 前置任务变化时 | 后续任务自动顺延或提前 | 日期保持不变，只在检查时提示冲突 |
| 资源冲突时 | 自动提示并可按资源日历调整 | 不自动调整，需要自己改 |
| 适合场景 | 需要关键路径、进度联动、甘特图自动更新的正式计划 | 日期已确定（如课程固定时间、会议）或临时占位任务 |
| 风险 | 需要正确设置工期、依赖、日历，否则日期会"乱跳" | 容易出现任务之间日期矛盾，甘特图不反映真实依赖 |

**本项目建议**：整体使用**自动计划**，只需要把"每周实训课"这类固定时间任务设为手动计划或加"不得早于/不得晚于"约束；录入完成后先在"任务"选项卡确认每个任务是自动还是手动（手动任务单元格左上角有绿色小三角），再录入实际进度（完成百分比）即可。

> 提示：如果发现日期被自动排到项目开始日期之前（历史日期），说明该任务是手动计划或存在"越早越好"以外的约束；删除约束或改为自动计划即可恢复。
