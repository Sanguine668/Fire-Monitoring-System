# 远距离识别与烟类检测能力升级 · 设计文档

- 项目：火情智能监测与预警系统（FireGuard AI）
- 版本：v1.0　｜　日期：2026-10-15
- 关联文档：《项目介绍与任务分工》《需求规格说明书》《2026-09-09 系统设计文档》、`docs/课程任务/数据集候选/远距离林区烟雾数据集候选.docx`
- 目标：补齐老师提出的两项要求——**远距离识别**与**提高检测准确率**，并形成可量化、可演示的优势证据

---

## 1. 背景与目标

当前系统的检测模型是**只认 fire 的单类模型**，训练数据 2,059 张、以近景大火为主（宽度中位数 598 像素，小目标仅占 14.7%）。这带来两个硬伤：

1. **完全没有烟雾检测能力**：数据集没有 smoke 标注，烟类只能靠公开模型兜底；
2. **没有远距离识别能力**：目标在远景画面里只有几个到几十个像素，模型训练时没见过这种尺度。

本设计通过"换数据 + 补推理方式"两条腿解决：用真实的小目标数据集重训模型，再在系统里加入**切片推理**，让远景小目标也能被捞出来。

## 2. 现状诊断（本次实测数据）

### 2.1 新数据集 D-Fire 体检结论

数据来源：Kaggle `sayedgamal99/smoke-fire-detection-yolo`（D-Fire 官方 Kaggle 版，CC0 公有领域），已下载并解压到 `datasets/d-fire/`。

| 检查项 | 结果 | 对项目的意义 |
| --- | --- | --- |
| 规模 | 21,527 张图 / 26,557 个标注框 | 是老数据集的 10 倍 |
| 划分 | train 17,221 / test 4,306，官方已划分 | 可直接采用 |
| 类别 | **0 = smoke（11,865 框）、1 = fire（14,692 框）** | **补上我们完全缺失的 smoke 标注** |
| 负样本 | 9,838 张无标注图 | 可用于降低误报 |
| 分辨率 | 宽度中位 1,061，≥1280 占 47.0%，最大 4,288 | 老数据集中位仅 598 |
| 目标尺度 | **小目标（框面积 <1%）占 44.6%** | 老数据集仅 14.7%，这是远距离识别的基础 |
| 完整性 | 缺图 / 缺标注 / 损坏 **0**；标注格式异常 26 行（宽高为 0 的退化框） | 数据可用，需过滤退化框 |

**类别编号的交叉验证**：D-Fire 官方类别数量为 fire 14,692、smoke 11,865，与实测的类别 1（14,692）、类别 0（11,865）一致；再用现有的 fire 单类模型做验证——类别 1 的图检出率 57%、平均置信度 0.377，类别 0 的图仅 15%、0.094。两条证据一致，确定 **0 = smoke，1 = fire**。

**划分泄漏检查**：D-Fire 由视频抽帧而来，需确认 train/test 是否混入相邻帧。实测 train 与 test 按编号连续分块（AoF: 0~6722 / 6723~8383；WEB: 0~9442 / 9443~11806），相邻编号跨集合的位置为 0 处，**不存在帧级泄漏**，评估结果可直接采信。

### 2.2 当前模型的基线

用现有模型（`ai/runs/fire26n/weights/best.pt`，fire 单类）在 D-Fire 上实测：

| 测试子集 | 检出率（conf ≥ 0.25） | 平均最高置信度 |
| --- | --- | --- |
| 纯火图（40 张抽样） | 57% | 0.377 |
| 纯烟图（40 张抽样） | 15% | 0.094 |

这组数字就是重训后要对比的**起点**：现有模型在火图上有一定能力但置信度偏低，对烟雾基本没有识别能力。

## 3. 方案

### 3.1 数据与划分

| 数据集 | 用途 | 处理方式 |
| --- | --- | --- |
| D-Fire train（17,221 张） | 主训练集 | 直接使用；过滤掉宽高为 0 的退化框 |
| D-Fire test（4,306 张） | 测试集 | 直接使用，保持官方划分 |
| D-Fire test 中的小目标子集（框面积 <1%） | **远景评估集** | 从 test 中筛选，单独评估远距离能力与切片推理效果 |
| gengyanlei VOC2020（2,059 张，近景 fire） | **域差异对照集** | **不并入训练**；仅用于验证"换域后模型在近景大火上是否退化" |

不并入老数据集的理由：老数据集偏近景、存在 57 组精确重复与 149 组近重复，合入会加剧近景偏置，也会让"指标提升"难以归因。

### 3.2 模型与训练

| 项目 | 设定 | 说明 |
| --- | --- | --- |
| 模型 | YOLO26n | 沿用，2.5M 参数，6GB 显存稳妥 |
| 类别数 | 2（fire / smoke） | 类别编号 0=smoke、1=fire |
| 输入尺寸 | imgsz 640 | 显存与速度的折中；远景提升主要由切片推理承担 |
| 训练轮次 | 80~100 epochs，patience 20 | 预计 40~80 分钟 |
| batch | 8（内存不足时降至 4） | 沿用首轮训练的避坑经验 |
| 评测指标 | mAP50、mAP50-95、每类 P/R、**小目标子集召回** | 小目标召回是远距离能力的直接证据 |
| 对比对象 | ① 现有 fire 单类模型（同一测试集）② 老数据集上的域对照 | — |

### 3.3 切片推理（系统功能）

**核心思路**：远景小目标在整图缩放到 640 后只剩几个像素，而把画面切成 640×640 的瓦片后，同样的小目标在瓦片里相对尺度变大，模型就"看得见"了。代价是每帧要推理多次，因此不能每帧都切。

**触发策略**：**按需切片**。

- 常规帧：整图推理（与现在一致）；
- 每隔 N 秒（默认 2 秒）执行一次**全图切片扫描**，逐片推理后跨片 NMS 合并；
- 远景烟雾的演变是缓慢的，2 秒的检测间隔可以接受；按每 2 秒扫描一次、每次 2~6 片计算，在 4 FPS 下平均每帧只增加约 0.25~0.75 次推理，切片能力可以**常开**。

**参数**（默认值，可在设置页调整）：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 切片开关 | 开 | 关闭时行为与现在完全一致 |
| 瓦片尺寸 | 640 | 与训练输入一致 |
| 重叠率 | 20% | 避免目标被切在瓦片边界 |
| 扫描间隔 | 2 秒 | 每路视频源独立计时 |
| 合并 IoU | 0.5 | 跨片去重 |

**模块改动**：

| 模块 | 改动 |
| --- | --- |
| `backend/app/detector.py` | 新增切片推理路径：按帧尺寸自适应分片、逐片推理、跨片 NMS 合并；返回结果中标记是否来自切片扫描 |
| `backend/app/worker.py` | 记录上次切片扫描时间，按间隔决定当前帧走常规还是切片路径 |
| `backend/app/db.py` / `settings` | 新增 `tiling_enabled`、`tile_size`、`tile_overlap`、`tile_interval` 四个配置项 |
| `backend/app/main.py` | 设置接口支持上述配置；检测事件中带出 `tiled` 标记 |
| `frontend` 实时监控页 | 显示"远距离模式"状态；检测框旁标注检出方式 |
| `frontend` 系统设置页 | 四个配置项的开关与数值 |

**关键设计约束**：切片推理**只改变推理方式，不改变模型**。因此它可以与重训并行推进，且在评估时能干净地隔离变量——同一模型下对比"整图 vs 切片"的召回率。

### 3.4 验证与演示

1. **切片推理有效性**：同一模型，在 D-Fire 小目标测试子集上对比整图推理与切片推理的召回率与误报数；
2. **重训效果**：新模型与现有 fire 单类模型在 D-Fire test 上的 mAP、每类 P/R、小目标召回；
3. **域差异检查**：新模型在老数据集（近景）上的表现，确认换数据后近景能力没有明显退化；
4. **演示方案**：一段远景视频，现场开关"远距离模式"对比检出结果；同时展示烟雾检出（现在完全没有的能力）；
5. **性能实测**：记录开启切片后的平均推理耗时与帧率，写入文档。

## 4. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| D-Fire 的域与手机拍摄差异大 | 重训后模型在手机拍的近景火上可能退化 | 用老数据集做域对照；若退化明显，训练时混入少量近景数据做加权 |
| 切片推理算力开销超预期 | 多路视频源时帧率下降 | 扫描间隔可调；先保证单路演示可用，多路时自动放宽间隔 |
| 训练时间受机器影响 | 耽误后续开发 | 训练与切片推理并行推进，互不阻塞 |
| 小目标子集样本量不足 | 评估结论不稳健 | 若子集过小，另外合成远景样本作为补充评估集 |

## 5. 执行顺序

| 顺序 | 内容 | 产出 |
| --- | --- | --- |
| 1 | 数据管线：统一目录结构、生成 `data.yaml`、过滤退化框、筛小目标评估子集 | 可训练的数据集 + 评估子集 |
| 2 | 重训与评测 | 双类模型 `best.pt` + 指标对比表 |
| 3 | 切片推理实现并接入系统 | 后端切片路径 + 设置项 + 前端展示 |
| 4 | 评估对比与演示准备 | 召回对比表 + 演示素材与脚本 |

## 6. 验收标准

1. 模型能同时检出 fire 与 smoke，且在小目标子集上的召回率**明显高于**现有 fire 单类模型；
2. 切片推理在远景评估集上相对整图推理的召回率有可量化的提升，且开启后单路演示帧率仍可接受；
3. 系统设置页可控制切片推理开关与参数，实时监控页能看到远距离检出的标记；
4. 上述结论均有实测数据支撑，且对比条件（同一测试集、同一模型）可复现。
