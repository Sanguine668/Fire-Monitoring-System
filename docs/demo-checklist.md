# FireGuard AI 演示清单（2026-10-22）

## 1. 当前已验证状态

- 模型：`ai/runs/fire26n-v2/weights/best.pt`（fire + smoke 双类）
- 官方 test：mAP50 0.724，mAP50-95 0.400
- 默认阈值：fire 0.40，smoke 0.45
- 默认开启：远距离切片（640 瓦片、20% 重叠、每 2 秒）、告警局部复核
- 已验证视频源：本地火灾视频、模拟 IP Webcam HTTP 流、远景视频；模拟手机流已换成“日落/路灯/蒸汽/普通场景 + 真实火情”的混合视频
- 后端：FastAPI 8000 端口；前端已构建并由后端直接托管

## 2. 启动系统

```powershell
$env:FIREGUARD_DEVICE='0'
ai\.venv\Scripts\python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```

浏览器打开 <http://127.0.0.1:8000>。局域网内其他设备可用 `http://电脑IP:8000`。

健康检查：

```powershell
curl http://127.0.0.1:8000/api/health
curl http://127.0.0.1:8000/api/model
```

`/api/model` 应返回 `{"0":"smoke","1":"fire"}`。

## 3. 手机推流（IP Webcam）

1. 手机开热点，电脑连接该热点（或两者连同一 WiFi）；
2. 手机安装 IP Webcam，分辨率建议 640×480 或 1280×720，格式 MJPEG；
3. 手机页面滑到底部点 **Start server**；
4. 进入系统「手机接入向导」，填写手机 IP（如 `192.168.43.1`），点「测试连接」；
5. 地址会自动补成 `http://192.168.43.1:8080/video`，保存为视频源；
6. 到「实时监控」查看画面、检测框和「远距离扫描」标记。

注意：是**电脑去连手机**，不需要手机访问电脑；只要电脑能访问手机 `8080` 端口即可。

IP Webcam 的「视频格式」选项只影响录制，不影响它自带的 MJPEG 地址；`/video` 仍可用。如果 `/video` 连不上，直接点向导里的 **「自动检测可用地址」**，系统会并行尝试：

- `http://手机IP:8080/video`（MJPEG）
- `http://手机IP:8080/videofeed`（部分版本）
- `http://手机IP:8080/shot.jpg`（JPEG 快照轮询，约 3 FPS）
- `rtsp://手机IP:8080/h264_ulaw.sdp`
- `rtsp://手机IP:8080/h264_pcm.sdp`

手动诊断：

```powershell
Test-NetConnection 192.168.43.1 -Port 8080
curl http://192.168.43.1:8080/shot.jpg -o shot.jpg
```

`Test-NetConnection` 不通说明是网络/IP 问题，不是视频格式问题。

## 4. 建议演示顺序（5–7 分钟）

1. **总览页**：展示模型 `smoke + fire`、远距离开、告警复核开、在线视频源数量；
2. **智能体协同页**：展示感知 / 远场 / 时序 / 复核 / 决策五个 Agent 的实时状态、最新决策轨迹和指标；右上角可切换视频源、暂停刷新（默认 3 秒采样，避免数字乱跳）；
3. **实时监控**：焦点模式下展示主画面 + 右侧缩略图；指出 fire/smoke 框、FPS、“智能体链路”状态条和远距离扫描标记；
4. **手机画面**：用 IP Webcam 实时拍一段烟雾/火焰视频（或手机屏幕上的火情视频），展示端到端识别；
5. **系统设置**：展示 fire 0.40 / smoke 0.45、切片 640 / 20% / 2 秒、复核阈值 0.25；
6. **告警中心**：先点「清空」，再让画面持续几秒，展示“智能体 已复核”、告警合并、累计次数、确认处理；
7. **效果数据**：官方 test mAP50 0.724、远景召回 81.2%（旧模型 18.5%）、SmokeFire 烟雾召回 90.8%。

## 5. 演示前 10 分钟检查

- 告警中心点一次「清空」，避免旧数据；
- 确认手机 IP Webcam 已 Start server，电脑能打开 `http://手机IP:8080/video`；
- 确认电脑插电，关闭不必要的高内存程序；
- 浏览器打开总览页，确认在线视频源数量正确；
- 如果视频源显示离线，删除后重新用向导添加。

## 6. 手机临时故障的回退方案

没有手机或网络不通时，用本机模拟 IP Webcam：

```powershell
ai\.venv\Scripts\python scripts\mock_phone_cam.py storage\uploads\demo_mixed.mp4 8080
```

然后在系统里添加 `http://127.0.0.1:8080/video` 作为 HTTP 视频源。

远景演示直接使用已添加的「远景演示」视频源（`storage/uploads/demo_farfield.mp4`）。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 手机源一直离线 | 确认 IP Webcam 已启动、地址是 `/video`、电脑与手机同一网络 |
| IP Webcam 没有 MJPEG 选项 | 不影响 `/video`；点「自动检测可用地址」，或改用 `/videofeed`、`/shot.jpg` |
| 没有检测框 | 检查阈值是否被调得过高；恢复默认 fire 0.40 / smoke 0.45 |
| 画面卡顿 | 关闭远距离模式，或把扫描间隔调大、瓦片尺寸调小 |
| 告警太频繁 | 提高阈值、增大连续帧数/冷却时间；演示前清空告警 |
| 8000 端口被占用 | `Get-NetTCPConnection -LocalPort 8000`，结束旧进程后重启 |
