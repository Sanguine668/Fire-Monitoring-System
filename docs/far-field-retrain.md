## 三、两轮训练的做法与依据

### 第一轮（30 epochs, imgsz 640）

```
起点      weights/fire26n-v2-best.pt（微调，类别顺序 0=smoke 1=fire 不变）

```
**结果**：召回 71.36% → 85.93%（+14.57 pp），精确率 74.41% → 83.48%（+9.07 pp）

### 第二轮（16 epochs, imgsz 960）— 按 README §四 加码

```
起点      第一轮 best.pt（继续微调）
epochs    16      imgsz 960     batch 32    workers 16
过采样    阈值 0.02→0.04，重复 ×3→×5  →  28,160 张
耗时      95 分钟（~5.7 min/epoch，880 iters，3 it/s，显存 12.0 GB）
```

**为什么这么选**：第一轮后召回 85.93%、精确率 83.48%（余量充足），瓶颈是召回。
- `imgsz 960`：远景烟雾是极小目标（常 <20 像素），640 输入下特征基本被下采样吃掉，960 保留更多细节

| 5 | `/mnt/sda3` 是 fuseblk(NTFS)，pscp 上传后文件变 `---x--x--x` | `bash script.sh` 报"权限不够" | `chmod 755` |
