# 手机画面最远可识别距离（远景测距说明）

> 适用版本：距离估算默认几何改为手机手持（`phone_handheld`：1.5 m 高 / 12° 俯角 / 66° 视场角）之后。
> 相关实现：`backend/app/distance.py`；相关评测：`docs/far-field-evaluation.md`。

## 1. 结论先行

**常见手机主摄（1080p 输出、水平视场角约 66°）最远可识别约 1.3 km，实际可靠范围在 1 km 以内；
4K 主摄或 2× 长焦最远约 2.6 km，实际可靠范围约 2 km。**

这里的“识别”指模型能在画面里稳定检出 28 px 高的烟柱；“可靠”是在 28 px 实测下限之上，
再扣除视频压缩、手持抖动、电子防抖裁切和大气抖动后的保守值。

## 2. 实测可靠下限与公式

远景评测（`docs/far-field-evaluation.md`，D-Fire 远景小目标子集 520 张）给出的实测可靠下限是
**目标框高 28 px**：低于 28 px 时远景召回明显下降，距离数字只剩提示意义。因此手机画面的
最大可识别距离由“25 m 高的烟柱在画面里刚好占 28 px”反推：

```text
f_px   = (frame_w / 2) / tan(hfov_deg / 2)      # 以像素为单位的焦距
d_size = f_px * target_height_m / bbox_height_px
```

以 1080p（1920×1080）、HFOV 66°、烟柱 25 m、框高 28 px 为例：

```text
f_px  = 960 / tan(33°)      ≈ 1478 px
d_max = 1478 * 25 / 28      ≈ 1320 m ≈ 1.32 km
```

火焰按 5 m 目标高度估算，同样 28 px 时只有烟柱的 1/5，即约 264 m；这不是缺陷，而是
“同样像素高度下火焰本身比烟柱矮得多”的必然结果。近处大火在画面里框高远大于 28 px，
由地面平面法给出几米到几十米的距离，不受这一上限影响。

## 3. 常见手机配置的远景上限

| 配置 | 画面分辨率 | 水平视场角 HFOV | f_px | 25 m 烟柱 @ 28 px | 实际可靠范围 |
| --- | --- | ---: | ---: | ---: | ---: |
| 1080p 主摄 | 1920×1080 | 66° | ≈ 1478 px | **≈ 1.32 km** | 约 1 km 内 |
| 1080p + 2× 长焦 | 1920×1080 | 35° | ≈ 3046 px | **≈ 2.72 km** | 约 2 km 内 |
| 4K 主摄 | 3840×2160 | 66° | ≈ 2956 px | **≈ 2.64 km** | 约 2 km 内 |

说明：

1. 2× 长焦按等效 HFOV 35° 估算（主摄 66° 的一半视角），实际值随手机型号在 30°–38° 之间浮动；
2. 4K 主摄的 f_px 由 3840 宽推出，但检测链路会把画面缩放到模型输入尺寸，**有效像素**取决于
   缩放后的框高，上表按原始 4K 帧中 28 px 计算；
3. “实际可靠范围”已按 0.75–0.8 的折减系数考虑压缩、抖动与防抖裁切，是保守值而非硬上限。

## 4. 假设与取值

| 假设项 | 取值 | 来源 / 说明 |
| --- | --- | --- |
| 烟柱目标高度 | 25.0 m | 平台沿用值（`distance.TARGET_HEIGHT_M["smoke"]`） |
| 火焰目标高度 | 5.0 m | 火苗远低于烟柱，避免近处火情被放大成几百米 |
| 最小可靠框高 | 28 px | 远景评测实测下限（低于 28 px 召回明显下降） |
| 1080p 主摄 HFOV | 66° | 常见手机主摄广角端（等效 26–28 mm） |
| 2× 长焦 HFOV | 35° | 主摄视角约一半 |
| 4K 主摄 HFOV | 66° | 与 1080p 主摄同镜头，仅分辨率不同 |
| 画面宽高比 | 16:9 | 1920×1080 / 3840×2160 |
| 安装高度 / 俯角 | 1.5 m / 12° | `phone_handheld` 预设默认值 |

## 5. 局限

1. **单视图几何**：只用一个检测框和固定目标高度假设反演距离，没有双目、IMU 或激光测距，
   不是测距仪读数；
2. **演示视频没有真实相机参数**：手机型号、实际 HFOV、俯角、防抖裁切都未知，本文按常见
   手机取值，换成其他机型会有系统性偏差；
3. **误差约 ±40%**：目标高度假设、框底贴合地面程度、镜头畸变都会放大误差，远景小框更明显；
4. **28 px 以下不保证**：低于实测下限的框只保留分级提示意义，不应作为处置依据；
5. **火与烟的差异**：同一距离下火焰框天然比烟柱小，远景火焰比远景烟雾更早触及 28 px 下限，
   因此“能看多远”对火和烟不是同一个数；
6. 距离会随镜头焦距、数码变焦、画面裁剪变化，换镜头或改分辨率后应重新按第 3 节公式核算。
